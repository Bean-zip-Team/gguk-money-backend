# **👉 Description**

오늘(당일) 탭 진행 현황을 조회하는 API입니다. 오늘 유효 탭 수, 오늘 지급받은 포인트 수, 다음 포인트/키캡 상자 지급까지 남은 탭 수를 확인할 수 있습니다. 당일 기록이 없으면 서버가 자동으로 오늘 자 기록을 생성한 뒤 응답합니다.

---

# 👉Request Header

| name | type | description |
| --- | --- | --- |
| Authorization | String | accessToken (type: Bearer) |

# 👉Request **Query Parameter**

없음

---

# **👉 Response**

### ✅ **성공 응답 예시**

### **Response Code**

`200`

### **Response Body**

| name | type | Description |
| --- | --- | --- |
| date | Date(String) | 조회 기준 날짜(yyyy-MM-dd, 서버 기준 오늘) |
| validTapCount | Integer | 오늘 인정된 유효 탭 누적 개수 |
| pointEarnedToday | Integer | 오늘 지급받은 포인트 개수 |
| remainingTapsToNextPoint | Integer | 다음 포인트 지급까지 남은 유효 탭 수 |
| remainingTapsToNextBox | Integer | 다음 키캡 상자 지급까지 남은 유효 탭 수 |
| boxProgressTapCount | Long | 현재 상자 세션의 진행 탭 수 |
| nextBoxRequiredTapCount | Integer | 다음 상자 획득에 필요한 누적 탭 수(절대값). `GET /api/keycap-boxes/status`의 동일 필드와 같은 값 |

```json
{
  "success": true,
  "data": {
    "date": "2026-07-15",
    "validTapCount": 245,
    "pointEarnedToday": 5,
    "remainingTapsToNextPoint": 32,
    "remainingTapsToNextBox": 118,
    "boxProgressTapCount": 162,
    "nextBoxRequiredTapCount": 280
  }
}
```

### ❌ **실패 응답 예시**

### **Response Code**

`401 Unauthorized`

### **Response Body (Access Token 누락/유효하지 않은 경우)**

```json
{
  "success": false,
  "error": {
    "code": "AUTH_REQUIRED",
    "message": "인증이 필요합니다."
  }
}
```

### **Response Code**

`404 Not Found`

### **Response Body (탭 진행도 데이터가 존재하지 않는 경우)**

```json
{

  "error": {
    "code": "TAP_PROGRESS_NOT_FOUND",
    "message": "탭 진행도를 찾을 수 없습니다."
  }
}
```
